# Quick Start Guide

Get up and running with LLM Animation Lab in under 5 minutes!

## 🚀 Instant Start (No Setup Required)

1. **Open the app**: Simply open `index.html` in your web browser
   - Double-click `index.html` in your file explorer, OR
   - Drag `index.html` into your browser

2. **Try it out**: Click one of the example buttons:
   - "Wave hello"
   - "Backflip"
   - "Victory dance"
   - "Jump and reach"

3. **Watch the magic**: The skeleton animates immediately in demo mode!

**That's it!** No installation, no API key needed for demo mode.

---

## 🎯 3-Step Workflow

### Step 1: Enter Your Prompt
Type what you want to see:
```
"Make the character do a backflip"
```

### Step 2: Generate
Click **"Generate Animation"** or press Enter

### Step 3: Watch & Control
- Animation plays automatically
- Use Play/Pause/Reset buttons
- Adjust speed with slider
- Scrub through timeline

---

## 🔑 Unlock Full Power (Optional)

### Get Custom Animations with Claude API

**Why?** Demo mode has 6 predefined animations. With an API key, you can create unlimited custom animations!

**Steps**:

1. **Get API Key**:
   - Visit [console.anthropic.com](https://console.anthropic.com)
   - Sign up (free credits available!)
   - Create an API key

2. **Add to App**:
   - Click **⚙️ Settings** in the app
   - Paste your key (starts with `sk-ant-`)
   - Key saves automatically

3. **Create Anything**:
```
"Have the character do a graceful ballet spin"
"Make them stumble and catch themselves"
"Animate a superhero landing pose"
```

**Cost**: ~$0.01-0.05 per animation

## 💡 Quick Tips

### Best Prompts
✅ **Be specific**: "Walk tiredly with slumped shoulders"
❌ **Too vague**: "Move"

✅ **Add emotion**: "Jump excitedly with arms raised"
❌ **No context**: "Jump"

✅ **Describe style**: "Wave hello enthusiastically"
❌ **Plain action**: "Wave"

### Use the Controls

**Speed Slider**:
- 0.25x = Slow motion (see details)
- 1.0x = Normal speed
- 2.0x = Fast motion

**Loop Checkbox**:
- ✅ On = Animation repeats
- ❌ Off = Plays once and stops

**Timeline**:
- Drag to scrub through animation
- See current time vs total duration

### Visual Settings

Toggle display options:
- **Show bones**: The connecting lines
- **Show joints**: The circular markers
- **Show joint names**: Labels for each joint

## 🆘 Troubleshooting

**Problem**: Skeleton doesn't appear
- **Solution**: Refresh page, check browser console (F12)

**Problem**: Animation doesn't generate
- **Solution**: Check internet connection (for API mode), try demo mode

**Problem**: Animation looks choppy
- **Solution**: Reduce speed to 0.5x, close other tabs

**Problem**: API key not working
- **Solution**: Verify key is correct, check account has credits
